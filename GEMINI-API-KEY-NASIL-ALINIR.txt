ADIM 1: GOOGLE AI STUDIO'YA GİT
===========================================

1. Tarayıcıda şu adresi aç:
   https://makersuite.google.com/app/apikey

   VEYA

   https://aistudio.google.com/app/apikey

2. Google hesabınla giriş yap
   (Gmail hesabınızı kullanabilirsiniz)


===========================================
ADIM 2: API KEY OLUŞTUR
===========================================

1. Sayfada "Get API Key" veya "Create API Key" butonunu gör

2. İki seçenek çıkacak:
   - "Create API key in new project" (Yeni proje)
   - "Create API key in existing project" (Var olan proje)

3. "Create API key in new project" seç
   (İlk defa kullanıyorsan bu seçenek)

4. Birkaç saniye bekle...

5. API key oluşturuldu! 🎉


===========================================
ADIM 3: API KEY'İ KOPYALA
===========================================

1. Ekranda uzun bir key göreceksin
   Örnek: AIzaSyAbc123def456ghi789jkl012mno345pqr678

2. "Copy" butonuna tıkla (sağ tarafta)

3. Key'i SAKLA! (Not defterine yapıştır)

⚠️ UYARI: Bu key'i KİMSEYLE paylaşma!
⚠️ UYARI: GitHub'a pushlama! (private key)


===========================================
ADIM 4: REPLİT'TE KULLAN
===========================================

Replit'te:

1. Sol menüde "Tools" → "Secrets"

2. Key: GEMINI_API_KEY
   Value: [Kopyaladığın key'i yapıştır]

3. "Add secret" butonuna tıkla

4. Bitti! Backend artık Gemini kullanacak ✨


===========================================
ADIM 5 (OPSİYONEL): AYARLARI KONTROL ET

Gemini'nin çalıştığını doğrulamak için:

   "✅ Using Gemini AI (FREE!) for text generation"
   "✅ Using Gemini Vision (FREE!) for image analysis"

===========================================
SORUN ÇÖZME
===========================================

❌ "Invalid API key" hatası
   → Key'i doğru kopyalamadın
   → Tekrar kopyala, başında/sonunda boşluk olmasın
   → Secrets'ta doğru yazdığından emin ol

❌ "API key not found" hatası
   → Replit'te GEMINI_API_KEY secret'ı ekledin mi?
   → İsim tamamen doğru yazılmalı (büyük harf önemli!)

❌ "Quota exceeded" hatası
   → Günlük limit dolduysa (1500 istek)
   → Yarın tekrar dene
   → VEYA yeni bir Google hesabı ile yeni key al

❌ Backend hala OpenAI kullanıyor
   → Secrets'ta AI_PROVIDER=gemini var mı kontrol et
   → Replit'i restart et (Stop → Run)
