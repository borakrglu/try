===========================================
ADIM 1: REPLİT HESABI AÇ
===========================================

1. https://replit.com adresine git
2. Sağ üstte "Sign up" veya "Log in" tıkla
3. GitHub ile giriş yap (en hızlısı)
   - "Continue with GitHub" butonuna tıkla
   - GitHub'da izin ver


===========================================
ADIM 2: PROJEYİ İÇE AKTAR
===========================================

1. Replit ana sayfasında "+ Create Repl" butonuna tıkla
   (Sağ üstte mavi buton)

2. "Import from GitHub" sekmesini seç
   (Üstte sekmeler var, ortadaki)

3. GitHub URL'ini yapıştır:
   https://github.com/borakrglu/try

4. "Import from GitHub" mavi butonuna tıkla

5. Bekle... (biraz sürebilir, dosyaları çekiyor)


===========================================
ADIM 3: ENVIRONMENT VARIABLES (ÇOK ÖNEMLİ!)
===========================================

Sol menüde "Tools" var (🔧 ikon)
   ↓

   ↓

---

5. Key'i kopyala ve buraya yapıştır

===========================================
SORUN ÇÖZME
===========================================

❌ "Run" butonu çalışmıyor
   → Shell sekmesine git
   → Şunu yaz: cd mystic-ai-backend && ./start-replit.sh
   → Enter bas

❌ "Permission denied" hatası
   → Shell'de yaz: chmod +x mystic-ai-backend/start-replit.sh
   → Sonra tekrar dene

❌ Backend açılıyor ama HTML bağlanamıyor
   → API_URL doğru mu kontrol et
   → https:// var mı?
   → Sonunda / var mi? (OLMAMALI!)

❌ "Failed to fetch" hatası
   → Replit'te backend çalışıyor mu kontrol et
   → URL'yi tarayıcıda aç: https://your-url.repl.co/health
   → {"status":"healthy"} görmeli

❌ OpenAI hatası
   → API key doğru mu kontrol et (Secrets'ta)
   → OpenAI hesabında bakiye var mı?

❌ Backend 5 dakika sonra uyuyor
   → Normal, bu Replit'in free özelliği
   → Tekrar kullanınca uyanır (10-30 saniye)
   → Always-on istiyorsan Replit Core ($7/ay)


===========================================
REPLİT'Tİ TEKRAR BAŞLATMA
===========================================

Backend'i restart etmek için:

1. YÖNTEM 1: Stop → Run
   - Üstte "Stop" butonu (■)
   - Sonra "Run" butonu (▶️)

2. YÖNTEM 2: Shell'den
   - Shell sekmesine git
   - Ctrl+C bas (durdur)
   - ./start-replit.sh yaz (başlat)

3. YÖNTEM 3: Repl'i yeniden başlat
   - Tarayıcıyı kapat
   - Replit'e tekrar git
   - Repl'i aç
   - Run'a bas


===========================================
GELİŞMİŞ: HER ZAMAN AÇIK TUTMA
===========================================

Replit free plan'da backend 5 dakika sonra uyur.
Her zaman açık tutmak için (hacky yöntem):

1. uptimerobot.com'a git (ücretsiz)
2. Hesap aç
3. "Add New Monitor" tıkla
4. Monitor Type: HTTP(s)
5. URL: https://your-repl-name.your-username.repl.co/health
6. Monitoring Interval: 5 minutes
7. Create Monitor

Bu her 5 dakikada bir /health'e istek atar,
backend uyanık kalır! 🎉
