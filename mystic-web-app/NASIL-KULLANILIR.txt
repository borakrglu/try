ÇOK BASİT! 3 ADIM:
===========================================

1️⃣ BACKEND'İ BAŞLAT (veya Railway'e koy)

   Seçenek A - Lokal (kendi bilgisayarında):
   - mystic-ai-backend klasörüne git
   - Docker varsa: docker compose up -d
   - Yoksa: Railway'e koy (Seçenek B)

   Seçenek B - Railway (internette):
   - https://railway.app → Giriş yap
   - "New Project" → "Deploy from GitHub"
   - borakrglu/try repo'sunu seç
   - mystic-ai-backend klasörünü seç
   - Environment variables ekle (OpenAI API key vs.)
   - Deploy!
   - Link gelir: https://your-app.railway.app


2️⃣ INDEX.HTML'İ AÇ

   - index.html dosyasını BUL
   - SAĞ TIKLAYIP "Birlikte Aç" → Chrome/Edge seç
   - VEYA dosyayı Chrome'a sürükle-bırak


3️⃣ BACKEND URL'İNİ AYARLA

   İlk açılışta hata alırsan:

   - index.html'i NOT DEFTERI ile aç
   - 10. satırı bul: const API_URL = 'http://localhost:8000';
   - Değiştir:
     * Lokal ise: http://localhost:8000 (değiştirme)
     * Railway ise: https://your-app.railway.app
   - Kaydet, tarayıcıda yenile (F5)

BACKEND DEPLOY (Railway):
===========================================

1. https://railway.app
2. GitHub ile giriş yap
3. New Project → Deploy from GitHub
4. borakrglu/try seç
5. Root directory: mystic-ai-backend
6. Environment Variables ekle:
   - OPENAI_API_KEY = sk-your-key
   - SECRET_KEY = your-secret
   - DATABASE_URL = (otomatik)
7. PostgreSQL database ekle (New → PostgreSQL)
8. Deploy!
9. Link al (Settings → Generate Domain)
10. index.html'de API_URL'i değiştir
